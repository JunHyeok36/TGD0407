# 01. 기획 개요 & 게임플레이

## 게임 개요

**TDG**는 카드와 유물 조합으로 덱을 구성하고, **틱(Tick) 단위로 동기화**되는 적의 행동을 제어하며  
그리드 기반 던전을 돌파하는 **덱빌딩 턴제 전략 로그라이크 게임**이다.

---

## 연출 방법

- 모든 게임은 **Isometric View** 의 XY Grid 위 판에서 여러 Entity가 상호작용하는 방식으로 진행된다.
- 플레이어는 화면을 회전하며 여러 방면으로 Room을 볼 수 있다.

### 그래픽 스타일

#### 메인 그래픽 — 3D 기반 픽셀 그래픽
- 3D 환경을 Post Processing 기술(픽셀화 + 툰 쉐이더)로 표시한다.
- 참고 : *t3ssel8r pixel shader*
- 전체적인 색상 톤은 레벨마다 고유 팔레트를 사용한다.

#### UI 그래픽
- CMD 콘솔을 연상시키는 **녹색·검은색** 기반 팔레트.
- **카드 그래픽**
  - 메인 팔레트와 다른 팔레트를 사용하여 차별화.
  - 카드 희귀도에 따라 다양한 프레임 색.
  - 각 카드를 간략히 표현하는 일러스트 포함.

---

## 핵심 플레이 가치

### 1. 로그라이크
- Map(던전)이 랜덤으로 생성되고, 플레이어는 끝까지 도달하여 최종 보스를 격파해야 한다.
- 다양한 경로를 통해 선택에 따라 다른 최종 보스를 조우할 수 있다.
- 일반 경로로 갈 수 없는 보물방 등 숨겨진 요소로 탐색 흥미를 유발한다.

### 2. 틱 기반 행동 동기화
- 일반 턴제와 달리 플레이어의 **한 번의 행동이 게임 전체의 시간(틱)을 즉시 전진**시킨다.
- 예: 플레이어가 1칸 이동 → 투사체들이 각각 2칸씩 이동.
- 틱마다 영향을 주는 요소가 플레이어 행동 대기 중에 예고 표시된다.

### 3. 계산적 전략 플레이
- 모든 적·투사체가 예측 가능한 법칙에 따라 움직이므로 플레이어는 위협 요소를 계산하여 위기 돌파가 가능하다.
- 예: 다음 틱에 복수의 투사체가 날아온다면, 궤적을 계산해 안전한 위치로 이동하거나 투사체 무력화 카드를 사용할 수 있다.

### 4. 행동의 연쇄 작용
- 카드·유물 조합이 단순 수치 강화를 넘어 복잡한 연쇄 효과를 유발한다.
- 예: "투사체 벽 튕김" 유물 + "피격 시 투사체 복제" 유물 + 투사체 발사 카드 → 투사체가 화면을 뒤덮는 상황 발생 가능.

### 5. 숨겨진 스토리
- 스토리가 표면적으로 드러나지 않고, 플레이어가 숨겨진 요소를 찾으면서 스토리가 있음을 알게 된다.
- 최종적으로 히든 엔딩 발견 가능.

## 부가 플레이 가치

| 가치 | 설명 |
|------|------|
| **친숙한 조작** | 카메라 플레이어 고정 기본, 엣지 스크롤 지원. 마우스 클릭으로 이동 (*LoL* 스타일) |
| **시각적 피드백** | 투사체 회피·보스 격파·퍼즐 해결 시 화려한 이펙트 + 소소한 보상 |
| **도전과제** | 구체적·숨겨진 도전과제 제공, 달성 시 소소한 영구 능력치 보상 |
| **카드로 표현하는 모든 상호작용** | 이동을 제외한 모든 상호작용(상인 구매·대화, 버튼 조작 등)은 카드로 진행. 탐색 모드에서만 등장 |

## 플레이 루프

```
[메인 캐릭터 선택] → [던전 진입]
→ <인게임 루프> {
    <N레벨 루프> {
        [레벨 탐색 및 진행] → [카드/유물 보상 획득 및 캐릭터 능력치 강화]
        → ([레벨 보스 격파]) → [다음 레벨 선택]
    }* → [최종 보스 격파]*
} → [경험치 획득] → [메인 캐릭터 시작 능력치 강화]

------------------------------------------------------------------------
[] : 일반 단계  |  <>{} : 블록  |  () : 생략 가능  |  * : 여러 번 반복 가능
```

- N : 레벨 개수. 플레이어 선택에 따라 최대값이 늘어날 수 있고, 최대 레벨 클리어 시 최종 보스 레벨로 이동.
- 경험치 : 게임 결과에 따라 획득하는 재화. 캐릭터 시작 능력치를 영구 강화한다.

## 인게임 플레이 모드

### Battle Mode (전투 모드)
- **트리거** : 특정 Room 진입 시 적대적 Entity 존재 또는 갑작스러운 적 등장
- 모드 진입 후 Exploration Mode 복귀 전까지 **다른 Room으로 이동 불가**
- 진입 즉시 플레이어 캐릭터와 적 Entity가 카드를 드로우하여 턴을 전개
- **해제 조건** : 모든 적대적 Entity 제거 또는 특정 조건 만족

### Exploration Mode (탐색 모드)
- **트리거** : 적대적 Entity가 없는 상태
- 모든 Room을 자유롭게 탐색 가능
- 플레이어 고유 카드 대부분 사용 불가; 이동과 의사결정 카드(Utility·Interaction)만 사용 가능

## UI 화면 구성

### 타이틀 화면
- 인게임과 동일한 Room 구조. 각 섹션별 Room을 이동하며 설정·기록·캐릭터 선택 진행.
- 참고 : *Spelunky 2*의 던전 진입 방식.
- 빠른 시작을 위한 콘솔 터미널 오브젝트 배치.

### 인게임 HUD

| 위치 | 내용 |
|------|------|
| 왼쪽 상단 | 캐릭터 초상화, 체력·쉴드·스테미나 바, 보유 유물 |
| 왼쪽 | 재화 정보 (골드, 보유 아이템) |
| 하단 | 덱 정보 (남은 카드 / 핸드 카드 / 버린 카드 / 카드 개수) |
| 상단 *(Battle)* | 턴 정보 |
| 오른쪽 상단 *(Battle)* | 상태효과 목록 |
| 오른쪽 상단 *(Exploration)* | 레벨 정보 |

### 인게임 Pause 화면
- 좌측 : 레벨·게임 정보
- 우측 : 게임 제어 메뉴
