# TGD0407

## 프로젝트 개요

**TGD0407**은 Unity 엔진을 기반으로 개발 중인 게임 프로젝트입니다.  
프로젝트명의 **TGD**는 게임 장르 또는 팀명의 약자이며, **0407**은 프로젝트 시작일(4월 7일)을 나타냅니다.

---

## 기술 스택

| 항목 | 내용 |
|------|------|
| 엔진 | [Unity](https://unity.com/) |
| 언어 | C# |
| 버전 관리 | Git / GitHub |

---

## 프로젝트 구조

```
TGD0407/
├── Assets/          # 게임 에셋 (스크립트, 씬, 프리팹, 리소스 등)
├── Packages/        # Unity 패키지 설정
├── ProjectSettings/ # Unity 프로젝트 설정 파일
└── README.md        # 프로젝트 설명 문서
```

---

## 시작하기

### 요구 사항

- Unity Hub 설치
- Unity 에디터 (권장 버전: 프로젝트에서 사용하는 버전 확인)

### 실행 방법

1. 이 저장소를 클론합니다.
   ```bash
   git clone https://github.com/JunHyeok36/TGD0407.git
   ```
2. Unity Hub에서 프로젝트 폴더를 열기합니다.
3. Unity 에디터에서 씬을 열고 플레이 버튼을 눌러 실행합니다.
