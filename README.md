# TDG — Tick Dungeon Game

> 카드와 유물 조합으로 덱을 구성하고, 틱 단위로 동기화되는 적의 행동을 제어하며  
> 그리드 기반 던전을 돌파하는 **덱빌딩 턴제 전략 로그라이크 게임**

---

## 핵심 특징

| 특징 | 설명 |
|------|------|
| 🎴 **덱빌딩** | 카드와 유물의 조합으로 플레이어가 직접 덱을 구성 |
| ⏱ **틱 기반 동기화** | 플레이어의 매 행동이 틱을 전진시켜 모든 Entity가 동기적으로 반응 |
| 🧮 **계산적 전략** | 모든 투사체·적의 궤적이 예측 가능하여 위협 요소를 사전 계산 가능 |
| 🗺 **로그라이크** | 랜덤 생성 던전, 런마다 다른 경로와 빌드 |
| 🔗 **행동의 연쇄** | 카드·유물 조합이 단순 수치 강화를 넘어 복잡한 연쇄 효과를 유발 |
| 📖 **숨겨진 스토리** | 표면에 드러나지 않는 이야기, 히든 엔딩 존재 |

---

## 기술 스택

- **엔진** : Unity (URP)
- **언어** : C# (.NET)
- **플랫폼** : PC 우선 (Windows/macOS), 모바일 포팅 고려 중
- **주요 패키지** : UniTask, DOTween, Addressables, Unity Input System
