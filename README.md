> **TDG**
카드와 유물 조합으로 덱을 구성하고, 틱 단위로 동기화되는 적의 행동을 제어하며 그리드 기반 던전을 돌파하는 덱빌딩 턴제 전략 게임
> 

# 연출 방법

- 모든 게임은 Isometric View의 XY Grid 위의 판에서 여러 `Entity`가 상호작용하는 방식으로 진행된다.
- 플레이어는 화면을 회전하며 여러 방면으로 `Room`을 볼 수 있다.

## 그래픽
- **메인 그래픽 - 3D 기반 픽셀 그래픽**
    - 3D 환경을 Post Processing 기술을 통해서 픽셀화 및 색상 단순화(툰 쉐이더)하여 표시한다. (*t3ssel8r pixel shader* 참조)
    - 전체적인 색상 톤은 각 레벨마다 알맞은 톤으로 사용한다.
- **UI 그래픽**
    - CMD 콘솔 그래픽을 연상하게 하는 녹색과 검은색을 기본 베이스로 확장된 팔레트를 갖는다.
    - **카드 그래픽**
        - 메인 팔레트와 다른 팔레트를 사용하여 차별화된 느낌을 준다.
        - 카드의 희귀도에 따라 다양한 프레임 색을 갖는다.
        - 카드에는 각 카드를 간략히 표현하는 그림을 갖는다.

## UI 화면

- **타이틀 화면**
    - 게임을 처음 시작할 때 볼 수 있는 화면
    - 인게임과 같지만 각 섹션 별로 나누어진 `Room`을 이동하면서 설정 값 변경, 플레이 기록, 게임 종료 등의 다양한 기능을 사용할 수 있고, 게임 모드와 캐릭터 선택 및 강화하여 인게임까지 분위기를 이어간다. (*Spelunky2* 게임의 던전 진입 방식 참조)
    - `Room`간의 이동으로 선택하는 것이 불편한 플레이어를 위해서 이전 선택 그대로 게임을 진행하는 옵션과 콘솔로 게임 시작을 할 수 있도록 컴퓨터 오브젝트를 배치한다.
- **인게임 UI 화면**
    - **왼쪽 상단** : 캐릭터 정보
        - 캐릭터 초상화
        - 체력, 쉴드 바, 스테미나 바
        - 보유 중인 유물 (일정 개수 이상은 `...`으로 표시)
    - **왼쪽** : 재화 정보
        - 골드
        - 보유 아이템 (일정 개수 이상은 `...`으로 표시)
    - **하단** : 덱 정보
        - 남은 카드
        - 핸드 카드
        - 사용된 카드
        - 카드 개수
    - **Battle Mode**
        - 상단 : 턴 정보
        - 오른쪽 상단 : 상태효과 정보
    - **Exploration Mode**
        - 오른쪽 상단 : 레벨 정보
- **인게임 Pause 화면**
    - **좌측** : 게임 정보
        - 레벨 정보
        - 게임 정보
    - **우측** : 게임 제어 메뉴

# 플레이 가치

## 핵심 가치

- **로그라이크**
    - 던전(`Map`)이 랜덤으로 생성되고 플레이어는 이 던전의 끝까지 도달하여 마지막 최종 보스를 격파해야 한다. 끝으로 가는 과정에서 다양한 경로를 통해 선택에 따라 다른 최종 보스를 조우할 수 있다.
    - 일반적인 경로로 갈 수 없는 보물방 등의 숨겨진 요소를 배치하여 플레이어의 흥미를 이끈다.
- **틱기반 행동 동기화**
    - “내 턴이 끝나고 적이 행동하는” 일반적인 턴제 게임과 다르게, 플레이어의 한 번의 행동이 게임 전체의 시간(틱)을 즉각적으로 전진시킨다.
    - 예를 들어, 플레이어의 캐릭터가 1칸 만큼 이동했다면 적이 플레이어를 향해 던진 여러 개의 투사체가 각각 플레이어를 향해 2칸씩 이동한다.
- **계산적인 전략 플레이**
    - 어느 정도 랜덤성이 존재하지만 모든 적과 투사체가 예측 가능한 정해진 법칙에 의해서 틱 단위로 움직이고 이는 다음 플레이어 행동을 대기할 때 표시되기 때문에, 플레이어는 여러 위험 요소들을 계산하며 위기를 돌파하는 플레이를 할 수 있다.
    - 예를 들어, 적이 플레이어를 향해 가로, 세로 방향으로 던진 여러 개의 투사체가 다음 틱에 플레이어에게 피해를 준다면 플레이어는 이를 최소화하거나 피하기 위해서 모든 투사체의 궤적을 계산하여 맞지 않는 위치로 이동하거나 투사체를 무력화/궤적을 변경하는 등의 특수한 카드를 사용할 수 있다.
- **행동의 연쇄 작용**
    - 카드와 유물의 조합으로 단순히 수치를 올리는 것을 넘어서, 투사체의 궤적이 바뀌고 적의 행동 반경이 변하는 등의 연쇄 적용을 플레이어가 설계하도록 할 수 있다.
    - 예를 들어, 투사체가 벽에 튕기는 특성의 유물과 피격시에 투사체가 확률에 따라 두 배로 늘어나는 유물을 가지고 캐릭터 고유의 카드를 통해 투사체를 벽을 향해 던지면 경우에 따라 투사체가 화면을 뒤덥는 상황이 발생할 수 있다.
- **숨겨진 스토리**
    - 이 게임은 스토리가 표면적으로 드러나지 않고 플레이어가 여러 개의 숨겨진 요소를 찾으면서 스토리가 있다는 사실을 알게 하고 최종적으로는 히든 엔딩을 발견할 수 있도록 한다.

## 부가 가치

- **친숙한 조작 방식**
    - 카메라는 기본적으로 플레이어에 고정되어 있으며, 카메라 고정을 해제하면 엣지 스크롤 방식으로 카메라를 이동시킬 수 있다.  플레이어 캐릭터는 마우스로 이동시킬 `Point`를 선택하여 해당 `Point`에 도달하기 위한 가장 가까운 경로로 이동시킬 수 있다. (*League of Legends* 게임 이동 방식 및 카메라 제어 방식 참조)
- **화려한 시각적 피드백**
    - 플레이어가 게임 중 투사체를 피하거나, 강한 보스를 격파하거나, 어려운 수수께끼를 해결하면 화려한 이펙트 효과과 함께 소소한 효과를 얻는다.
    - 예를 들어, 플레이어 캐릭터를 향해 다가오는 투사체가 다음 틱에 캐릭터에게 피해를 주는 상황에서 해당 투사체를 피한다면 캐릭터의 피하는 애니메이션과 함께 일정 스테미나를 회복한다.
- **다양한 도전과제**
    - 다양하면서도 구체적인 도전과제를 통해서 플레이어의 도전 의욕을 이끌어 낸다. 또한 숨겨진 도전과제도 배치한다. 이를 달성했을 때는 소소한 보상을 지급한다.
    - 예를 들어, “투사체 연속으로 10번 피하기”, “보스 적을 1틱만에 파괴하기” 등이 존재한다. 이를 달성했을 때는 체력 10% 증가 등의 소소한 사전 능력치를 얻는다.

# 플레이 루프

```smalltalk
[메인 캐릭터 선택] -> [던전 진입] 
-> <인게임 루프> {
	<N레벨 루프> {
		[N레벨 탐색 및 진행] -> [카드/유물 보상 획득 및 캐릭터 능력치 강화] 
		-> ([레벨 보스 격파]) -> [다음 레벨 선택]
	}* -> [최종 보스 격파]*
} -> [경험치 획득] -> [메인 캐릭터 시작 능력치 강화]

--------------------------------------------------------------------------
[] : 일반 단계
<>{} : 블록
() : 생략 가능
* : 여러번 반복 가능
```

- `N` : 게임의 레벨 개수, 플레이어의 선택에 따라 최대값이 늘어날 수 있고 최대값에 도달한 레벨을 클리어하면 최종 보스 레벨로 이동할 수 있다.
- `경험치` : 게임 결과에 따라 획득할 수 있는 재화, 캐릭터의 시작 능력치를 강화할 수 있다.

## 인게임 루프

- 일반 모드, 무한 레벨 모드, 보스 격파 모드 등 여러 게임 모드가 존재한다.
- 플레이어는 Battle Mode와 Exploration Mode 사이에서 전환되면서 캐릭터를 제어할 수 있다.
- 플레이어는 각 레벨을 탐색 및 진행하면서 카드/유물/골드 보상을 획득하고 이를 바탕으로 캐릭터의 능력치를 강화한다.
- 틱마다 행동하는 `Entity`가 존재하면 다음 틱에 영향을 주는 요소를 플레이어 행동 대기 중에 확인할 수 있다. 플레이어는 이를 보고 다음 틱에 할 최적의 행동을 계산해야 한다.
- 최종적으로 레벨의 보스 및 최종 보스를 격파하여 경험치를 얻고 이를 통해 캐릭터의 시작 능력치를 강화한다.

### 플레이 모드

- **Battle Mode**
    - 특정 `Room`에 진입할 때 남아있는 적대적 `Entity`가 존재 또는 적대적 `Entity`가 갑자기 나타나면 발생하는 모드
    - 이 모드에 한번 진입하면 다시 Exploration Mode로 전환되기 전까지는 다른 `Room`으로 자유롭게 이동할 수 없다.
    - 모드 진입 즉시 플레이어의 캐릭터와 그에 적대하는 `Entity`는 카드를 드로우하고 고유의 카드와 함께 턴을 전개한다.
    - 모든 적대적 `Entity`를 제거하거나, 특정 조건을 만족하면 해제되고 Exploration Mode로 전환된다.
- **Exploration Mode**
    - 적대적 `Entity`가 존재하지 않을 때 모든 `Room`을 돌아다니며 탐색할 수 있는 모드
    - 플레이어 캐릭터의 고유 카드는 대부분 사용할 수 없고, 기본적으로 이동과 현재 소유하고 있는 의사 결정 카드만 사용이 가능하다.
